## 1. 首次登录与初始化

### 1.1 拿到登录信息

安装脚本执行完成时会输出三样东西,**请立即保存**:

```
面板地址:   http://服务器IP:随机端口/随机安全入口
管理员账号: 随机生成
管理员密码: 随机生成
```

找不到输出可重新查看:`cat /opt/kunpanel/data/initial_password.txt`(安装后首日有效)。

### 1.2 登录后建议立刻做的三件事

进入 **面板设置**:

1. **修改管理员密码**(设置 → 修改密码):改密后所有旧会话强制下线
2. **记下安全入口**:入口关闭时可直接用 `http://IP:端口` 访问;开启后必须带入口路径,忘了入口将无法登录
3. **绑定 TOTP 两步验证**(可选但强烈建议):用 Google Authenticator 等 APP 扫码,登录需再输动态码

### 1.3 忘记密码

```bash
/opt/kunpanel/bin/kunpanel reset    # SSH 到服务器执行,按提示重置
```

重置后所有登录会话失效。

## 2. 网站管理

### 2.1 创建网站

**网站 → 创建网站**,三种类型:

| 类型 | 适用场景 | 必填项 |
|---|---|---|
| **静态站点** | HTML/CSS/JS 纯静态网站 | 域名;根目录留空自动生成 |
| **PHP 站点** | WordPress / ThinkPHP 等PHP 程序 | 域名 + PHP 版本(需先在应用商店安装 PHP 运行时) |
| **反向代理** | Go/Node/Java 等本地服务,或任意外部服务 | 域名 + 目标 URL(如 `http://127.0.0.1:3000`) |

**反向代理进阶选项**:

- **发送域名 Host**:转发给上游的 Host 请求头,默认 `$http_host`(访客原始域名)。上游按域名区分站点时(如 Nginx/宝塔二次反代),在此直接填目标域名,无需改上游配置
- **负载均衡**:设置 → 负载均衡后端,每行「地址 [权重]」,多个后端自动加权轮询

### 2.2 站点类型互相转换

网站 → **设置 → 转换站点类型**:静态 / PHP / 反向代理可随时互转,转换即改写配置并立即生效,**原目录与数据保留**。

- 转为反向代理:需填反代目标
- 转为 PHP:选择运行时版本
- 转回静态:按站点根目录提供文件

### 2.3 常用站点功能(设置弹窗内)

| 功能 | 说明 |
|---|---|
| 域名管理 | 每行一个,保存即重载生效 |
| HTTPS | 绑定证书 + 强制 HTTPS 跳转(见下节 SSL) |
| 密码访问 | 浏览器标准 Basic Auth 弹窗 |
| 防火墙与缓存 | 防盗链(Referer 白名单)、浏览器缓存 30 天、流量限速、安全响应头、维护模式(503 页面) |
| 伪静态 | 常用程序预设 + 自定义 |
| 备份 | 打包下载 / 服务端留存 / 上传恢复(原子化,失败不伤原站) |

### 2.4 批量操作

列表勾选多个站点(支持全选)→ **批量删除**。删除只移除面板配置,**网站根目录数据保留**。

### 2.5 重载与生效规则

所有网站配置保存后自动做 `nginx -t` 语法校验,**校验失败自动还原并提示**,不会出现保存错误配置导致整站打不开的情况。

## 3. SSL 证书

**网站 → SSL 证书**:

1. **Let's Encrypt 自动申请**(推荐):站点 → HTTPS → 选择 LE,HTTP 文件验证,自动续期;支持测试环境(staging)预签调试
2. **上传现有证书**:粘贴 PEM 证书 + 私钥
3. **自签证书**:本地测试用,浏览器会提示不安全

绑定方式:站点 → HTTPS → 选择证书 → 开启强制 HTTPS。

证书过期前 30 天面板自动尝试续期(LE 证书),消息中心会提示结果。

**批量管理**:证书列表支持勾选批量删除;被站点占用的证书会逐项提示,不影响其余删除。

## 4. 面板迁移(宝塔 / 1Panel)

**网站 → 宝塔迁移 / 1Panel 迁移**,与两个主流面板双向互通。

### 4.1 宝塔 → 坤面板(同机或远程)

1. 网站页 → **宝塔迁移**(检测到本机宝塔时显示);宝塔在别的服务器时选「远程宝塔 → 本面板」页签
2. 远程迁移只需输入宝塔服务器 **IP + SSH 端口 + root 密码** → 连接检测(首次回显指纹)→ 勾选站点/数据库 → 开始迁移
3. 迁移内容:域名、网站文件(流式搬运)、SSL 证书(导入+自动重签接管续期)、伪静态与自定义规则(**保真保留**)、计划任务(自动注释宝塔原任务防双跑)、数据库(可选)

### 4.2 1Panel → 坤面板

同上,**1Panel 迁移**按钮独立入口:本机迁入(自动识别 /opt/1panel)、远程迁入(输入 IP 密码)、数据库从 1Panel MySQL 容器导出导入。

### 4.3 零停机与回滚

- 迁移过程中源面板站点**照常运行**
- 迁移完成后确认站点正常,再点「切换流量」:面板自动停用源面板网关(禁自启)、接管 80/443,并**逐域名×逐路径验证状态码**,任何异常自动回滚
- 反代/PHP 上游迁移后自动**回源旧机**(DNS 切换前零停机)
- 「回滚到宝塔/1Panel」一键恢复,源面板数据全程未动

### 4.4 坤面板 → 宝塔 / 1Panel(反向导出)

想把站点迁回去:勾选站点 → 导出到目标面板,自动生成对应配置并重载。

## 5. 应用商店与 PHP 多版本

**应用商店**:17+ 应用一键部署(WordPress、Nginx、OpenResty、MySQL、Redis、phpMyAdmin、Uptime Kuma、坤发卡、NAT Cloud 等)。

- 安装 = 自动写 compose + 拉镜像 + 启动,全程任务日志可见
- **多版本 PHP**:可同时安装 8.2 / 7.4 等,不同站点绑定不同版本
- **自定义应用**:粘贴 docker-compose,在线校验后入库

> 提示:安装 MySQL 建议小内存机器(≤2GB)在安装后适当调小 InnoDB 缓冲;同名应用已安装时重复安装会明确提示,不会覆盖现有实例。

## 6. 数据库管理

**数据库** 页:

- 创建数据库(选择实例,自动建库建账号)
- **SQL 控制台**:直接执行 SQL
- 备份/恢复:一键导出 `.sql.gz`,支持下载与恢复
- root 改密:改完自动同步面板连接配置

迁移来的数据库(宝塔/1Panel)导入后,记得把站点连接串改到面板 MySQL(默认 `127.0.0.1:3306`,以数据库页显示为准)。

## 7. 容器管理

**容器** 页:Docker 未安装时一键安装(自动配国内镜像源)。

- 容器:启停/重启/删除、**终端**、日志、资源限制(CPU/内存)热更新、日志轮转
- 镜像/网络/数据卷管理,清理悬挂镜像
- **容器端口管控**:Docker 发布的端口不经过系统防火墙,这里可按端口封禁外部访问(写入 DOCKER-USER 链)

## 8. 文件管理

**文件** 页:

- 拖拽上传 / 远程下载(服务器间拉取)/ 压缩解压(zip/tar.gz)/ 权限修改
- **在线编辑器**:CodeMirror 高亮 13 种语言,保存前自动备份,**历史版本可回滚**
- 全文搜索:按文件名或文件内容搜索
- **回收站**:删除的文件先进回收站,可恢复;设置定期自动清理

> 建议敏感操作前先用「压缩」做一次快照。

## 9. 计划任务

**计划任务 → 添加任务**,七种类型:

| 类型 | 用途 |
|---|---|
| Shell 脚本 | 自定义命令,标准 5 位 cron 表达式(可视化选择周期) |
| 目录备份 | 打包指定目录,保留 N 份,可选上传 SFTP 远程 |
| 日志切割 | 轮转站点日志并归档压缩 |
| 数据库备份 | 按库备份面板 MySQL/MariaDB,保留 N 份 |
| 回收站清理 | 自动清理超过 N 天的回收站条目 |
| 面板备份 | 打包面板全部配置 |
| 容器日志清理 | 清空运行中容器日志文件 |

每个任务可查看执行日志、上次结果与下次执行时间;支持手动触发、启停。

> 迁移自宝塔的任务会保留原启用/停用状态,宝塔原 crontab 行自动注释防双跑。

## 10. 安全中心与 WAF

### 10.1 WAF 防火墙(需 OpenResty 或定制 Nginx)

- **CC 攻击防御七种模式**:限流 403 / 5 秒跳转 / JS 无感 / Cloudflare 风格 Verifying / 点击 / 算术验证码 / 滑块
  - **人机验证模式选完即全站启用**:首次访问先验证,通过后 60 分钟(可调)免验
  - 阈值含义:限流模式 = 触发上限;验证模式 = 已验证访客的频率上限
- **黑白名单**:IP(支持 CIDR)、URL、UA;搜索引擎蜘蛛白名单(可选严格反向 DNS 验证)
- **拦截日志**:按类型/IP 筛选,一键封禁;自动封禁超阈值 IP(私网防误伤)
- **全局设置**:敏感文件拦截、危险方法拦截、空 UA 拦截、HTTP/1.0 拦截、目录扫描防御、蜜罐路径、安全响应头

### 10.2 系统安全

- 一键体检 9 项评分,按建议逐项加固
- SSH 安全:端口修改、密码认证开关
- 系统防火墙(ufw/firewalld)可视化管理

### 10.3 面板自身安全建议

1. 开启**安全入口**(设置 → 安全入口)
2. 开启 **TOTP 两步验证**
3. 不需要时关闭 ICMP(ping)
4. 面板端口建议改为高位端口

## 11. 监控与拨测

### 11.1 网站拨测

**监控 → 拨测监控 → 添加监控**:

- HTTP(填 URL)或 TCP(填 host:port)
- 每分钟探测一次,连续失败 2 次判定宕机,恢复时再次通知
- 保留 24 小时历史(可用率、延迟条带图)

### 11.2 监控中心

- **进程管理**:按 CPU/内存排序,终止进程
- **系统服务**:systemd 服务启停
- **网络工具**:ping / 端口扫描 / DNS / HTTP 检测 / 路由追踪

系统 CPU/内存/磁盘 IO/网络 24 小时历史在概览页图表(每分钟采样)。

## 12. 告警推送

**面板设置 → 告警推送**,支持邮件 / 钉钉 / 飞书 / Webhook。

触发场景:网站宕机与恢复、证书即将过期、计划任务失败、每日威胁摘要等。多渠道可同时启用,面板内消息中心同步留痕。

## 13. 面板设置与在线更新

**面板设置**:

- 修改端口 / 安全入口 / 管理员密码(改密全端下线)/ 面板名称
- 面板 SSL:上传证书一键开启 HTTPS
- 语言与外观(深色模式)
- **在线更新**:一键升级到最新版(国内自动走加速通道,SHA-256 校验保证完整性与来源)
- 面板备份/恢复:打包全部配置,换机迁移利器

> 更新不会影响网站与数据;更新后浏览器若提示版本变化,刷新页面即可。

## 14. 常见问题 FAQ

**Q1:忘记管理员密码?**
SSH 执行 `/opt/kunpanel/bin/kunpanel reset`,按提示重置。重置后所有会话下线。

**Q2:忘了安全入口/端口?**
入口在 `/opt/kunpanel/data/config.json` 的 `entrance` 字段(空=关闭);端口同文件 `port` 字段。或在面板设置里改。

**Q3:国内服务器 GitHub 连不上?**
安装脚本与面板「在线更新」已内置加速兜底,无需操作;手动下载也可用 Release 资产离线安装(`--offline`)。

**Q4:Docker 发布的端口外面能访问,防火墙没拦?**
Docker 直接写 iptables DOCKER 链,绕过 ufw/firewalld。到 **安全 → 容器端口管控** 封禁,或用 WAF 管控。

**Q5:网站打开显示 404/502?**
- 404:静态站检查根目录是否有 index 文件;反代站检查上游服务是否存活
- 502:上游挂了或端口不对;反代站检查「代理目标」,迁移站点确认上游服务已启动
- 看站点错误日志:网站 → 站点日志

**Q6:CC 防护开了,为什么访问没出验证页?**
人机验证通过后有免验期(默认 60 分钟),期间不会再弹。用无痕窗口或清除站点 Cookie 再试。想每次都验证,把「验证有效期」调小。

**Q7:一台机器能同时装宝塔和坤面板吗?**
能装,但两者会抢 80/443。建议用「宝塔迁移」把站点迁过来后执行「切换流量」,面板会自动停用宝塔 Nginx 并禁其自启(随时可一键回滚)。

**Q8:迁移后想换回原来的面板?**
迁移页提供「回滚」:自动恢复源面板网关与端口,源面板数据全程未动。

**Q9:如何备份数据面板配置?**
面板设置 → 面板备份(或计划任务 → 面板备份定时执行),下载 `.tar.gz` 保存;恢复在上传后一键完成。

**Q10:升级会影响网站运行吗?**
升级仅替换面板二进制,网站/Nginx/容器全部不受影响;升级中断电等极端情况,重启面板即可恢复(配置落盘均为原子写)。
